# Sun Powder Design System

## Read first
- `README.md`, `colors_and_type.css`, `index.html`

## Non-negotiables
1. Wordmark always lowercase: `sun powder` / `drinkable skin defense`
2. Every claim ends with `†`
3. No emoji
4. Only use palette in `colors_and_type.css`
5. Söhne Breit display, Söhne body, Söhne Mono specs
6. Voice: dermatologist to smart patient, calm and clinical
7. Use canonical pricing tiers from README

## Patterns
- 5 R's always in order: Regenerate · Resist · Reduce · Reverse · Restore
- Credibility row: Third Party Tested · Clinically Studied · Made in the USA · cGMP Facility
- Primary CTA: heat-gradient pill `Shop Sun Powder →`
- Long-form prose: navy-on-cream. Hero/pricing: navy-glow or orange-glow surfaces.
